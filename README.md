# Project Overview

This project investigates the capability of modern deep learning models to distinguish **real photographs** from **AI-generated images**.

The research compares multiple convolutional neural network (CNN) architectures on large-scale datasets containing images generated by different AI image synthesis models.

The objective is to determine which architecture provides the best generalization performance against unseen AI-generated images.

---

# Research Objectives

- Detect AI-generated images
- Compare multiple CNN architectures
- Evaluate model generalization across different generators
- Perform comprehensive dataset analysis
- Benchmark deep learning models using standardized evaluation metrics
- Evaluate performance on real-world AI-generated images
